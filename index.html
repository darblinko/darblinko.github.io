Retrieval and evaluation

golden-goose

Agentic RAG for medical device audit support, with revision-aware retrieval, SQL and graph routing, and a hash-chained audit log.

One recorded run on a synthetic corpus, with fake LLM, embedding, reranker and OCR providers, passed all seven metric gates, with 94.4% recall at 10 and 98.1% routing accuracy. Answer quality from a hosted LLM was not measured.

More engineering work

  • cypher-guard

    Checks model-written Cypher for read-only access and tenant scope before it reaches the database. The first version accepted 19 queries that read another tenant's data; the revised checker rejects all 19.

    ResultsSource
  • agent-controls

    Codex sandboxing with bubblewrap, cross-agent review and per-profile Claude Code configuration. A Stop-hook gate runs the tests and a Codex review of uncommitted changes, with at most 2 review verdicts per batch of changed files. A change to the git status output, including staging, starts a new batch; failed tests and reviewer errors use no round; at the cap Claude may stop with blockers open, which are logged.

    ResultsSource
  • industrial-monitor

    Vibration monitoring over MQTT with FFT and envelope anomaly detection, and a maintenance assistant that cites its sources. On a second simulated plant (seed 202), with the threshold frozen after calibration on the first (seed 101), it detected 94.8% of 1,805 fault windows and raised false alarms on 0.86% of 1,395 healthy windows, as recorded in results/detection.json at industrial-monitor 1a1dd5f. All sensor data is simulated.

    ResultsSource
