More engineering work

  • agent-controls

    Codex sandboxing with bubblewrap, cross-agent review and per-profile Claude Code configuration. A Stop-hook gate runs the tests and a Codex review of uncommitted changes, with at most 2 review verdicts per batch of changed files. A change to the git status output, including staging, starts a new batch; failed tests and reviewer errors use no round; at the cap Claude may stop with blockers open, which are logged.

    ResultsSource
  • industrial-monitor

    Vibration monitoring over MQTT with FFT and envelope anomaly detection, and a maintenance assistant that cites its sources. On a second simulated plant (seed 202), with the threshold frozen after calibration on the first (seed 101), it detected 94.7% of 1,805 fault windows and raised false alarms on 0.93% of 1,395 healthy windows, as recorded in results/detection.json at industrial-monitor 8e74634. All sensor data is simulated.
