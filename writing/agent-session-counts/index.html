Ten thousand coding-agent sessions: what the counts show

From 2026-04-15 to 2026-10-08 the Claude Code local stats cache recorded 10,202 sessions and 282,405 messages. Codex CLI wrote 2,195 session files from 2026-04-26 to 2026-10-26. Two days in August hold 59 percent of the Claude Code sessions and 5.5 percent of its messages. The counts record volume and timing; none of them measures the quality of the work.

What was counted and how

Two local records were read. Each tool writes its own record on the machine where it runs.

  • Claude Code keeps a stats cache file in its configuration directory. The file holds one entry per active day with three counts: sessions, messages and tool calls. It also holds per-model token totals and a few summary fields. It was last computed on 2026-10-08, so its daily entries run from 2026-04-15 to 2026-10-08.
  • Codex CLI writes each session to a rollout file in a directory named by year, month and day. The files were counted by the date in that path, up to and including 2026-10-27, the last complete day before measurement. For every counted file the date in the file name matches the date in the path.

Nothing else was read. No transcript, prompt or session file content was opened. The figures below are sums of the daily entries or of the file counts, grouped by 14-day period, by ISO week (Monday start) or by calendar month.

The files define little. The stats cache does not state what it counts as a message or as a tool call, or whether a subagent run counts as a separate session. This article uses the counts as recorded.

Claude Code: 134 entries in the dailyActivity array of the stats cache, first 2026-04-15, last 2026-10-08. The lastComputedDate field is 2026-10-08.

Codex CLI: 2,197 rollout files were present at measurement on 2026-10-28. Two are dated 2026-10-28 and fall after the cutoff, which leaves 2,195. Path date and file name date match for all 2,197.

Claude Code counts

Claude Code was active on 134 of the 177 calendar days from 2026-04-15 to 2026-10-08. On the median active day the cache recorded 7 sessions and 1,452 messages. Over the whole period there were 0.59 tool calls per message.

Two-week message totals peak at 41,284 in the period starting 2026-05-25. Grouped by ISO week instead, the peak is 30,170, in the week starting 2026-08-10. The peak depends on the grouping. The highest single day is 2026-09-09, with 17,728 messages in 14 sessions. The cache has no entry for any day in the week starting 2026-06-15.

Sessions and messages are distributed differently. August holds 7,345 of the 10,202 sessions (72.0 percent) and 26.1 percent of the messages. Most of the August sessions fall on two days: 2026-08-13 and 2026-08-14 record 6,001 sessions between them.

The per-model totals list 12 model identifiers and 206,473,081 output tokens. The largest share belongs to claude-opus-5, with 75,499,452 output tokens (36.6 percent). The file does not state the period those totals cover. Its daily per-model series starts later, on 2026-07-18.

Totals: sessionCount, messageCount and toolCallCount summed over the 134 daily entries. The sums equal the file's totalSessions (10,202) and totalMessages (282,405) fields. The file has no total field for tool calls.

Active days: 134 entries. 2026-04-15 to 2026-10-08 inclusive is 177 days. Medians are taken over the 134 entries. Tool calls per message: 167,392 divided by 282,405 is 0.593.

Period figures: messageCount summed over 14-day periods from Monday 2026-04-13, and separately by ISO week. Peak day: the entry with the highest messageCount. No entry is dated 2026-06-15 to 2026-06-21.

August: 7,345 of 10,202 sessions; 73,811 of 282,405 messages. Daily entries: 2026-08-13 has 2,599 sessions, 2026-08-14 has 3,402.

Models: the 12 keys of modelUsage, outputTokens summed. dailyModelTokens has 71 entries, 2026-07-18 to 2026-10-08.

Codex CLI session files

Codex CLI session files are dated on 131 distinct days, with a median of 7 files per active day. June holds 946 of the 2,195 files (43.1 percent). One day, 2026-06-25, holds 455 (20.7 percent). Inside the Claude Code window, 2026-04-15 to 2026-10-08, there are 2,133 Codex files.

A session file and a Claude Code session are different units, counted by different tools. This article does not add them together or compare their sizes.

What the counts cannot show

Quality of the output

Neither record says whether a session produced working code, passed its tests, was reviewed or was kept. A message count measures traffic between the user, the model and its tools. These counts support statements about volume and timing and no others.

Length of a session

Messages per session range from 10.0 in August to 1,171.8 in April, a factor of 116.6. The longest session in the cache has 4,361 messages and a recorded duration of 224.9 hours, starting 2026-05-13.

The monthly ratio divides the messages recorded in a month by the sessions recorded in that month. The daily session counts sum to the file's session total. Inference: each session is counted on one day, and a session that runs across several days can add messages to a month in which it is not counted as a session. The ratio is an approximate indicator for that reason.

Automated sessions

The stats cache does not mark a session as interactive or scripted. The Codex file names do not either. On 2026-08-13 and 2026-08-14 the cache records 6,001 sessions and 15,439 messages, 2.57 messages per session. Inference: these are scripted runs that each send one prompt and exit. Without those two days the cache holds 4,201 sessions and 266,966 messages, 63.55 messages per session. Inference: the 455 Codex files dated 2026-06-25 are a scripted batch of the same kind.

Coverage

  • The stats cache stops at 2026-10-08, 20 days before this article was drafted.
  • The stats cache belongs to one Claude Code configuration directory. Inference: sessions run under a separate configuration directory are recorded there and are absent from these counts.
  • The Codex count is of files present on 2026-10-28. Files deleted before then are not counted. This article did not determine whether any were deleted.
  • A resumed Codex session may write to an existing file or to a new one. This article did not determine which, because it did not open the files.

Monthly ratios: monthly sums of messageCount divided by monthly sums of sessionCount. Unrounded, 14,062 divided by 12 is 1,171.83 and 73,811 divided by 7,345 is 10.05; the factor is 116.6.

Two days: daily entries for 2026-08-13 and 2026-08-14. 6,001 of 10,202 sessions is 58.8 percent; 15,439 of 282,405 messages is 5.5 percent. The remainder is 10,202 minus 6,001 and 282,405 minus 15,439.

Controls used with these sessions

The controls used with these sessions are sandbox and review-gate scripts, published as darblinko/agent-controls. Neither record logs when a control ran, blocked an action or changed a result. This article makes no claim about their effect.

The stats cache fields are dailyActivity, dailyModelTokens, modelUsage, longestSession, hourCounts and summary totals. None records a control event.
